Agent4Sci 使用指南

一个跑在自己电脑上的科研 Agent 工作台。这份文档用一个真实课题走一遍：怎么把一个"我要做这个题"变成一份带引用的综述和一张能复现的图。

面向第一次用它的同事 · 全文约 15 分钟 · 跟着做约 1 小时

这个软件不是"聊天框 + 搜索"。它的核心是五件东西：对话里干活的 Agent、记忆记住课题常识、主对话把活分出去、Loop 把固定流程跑起来、主理人给你的领域造配置。下面先一句话说清每个是什么，再用一个课题串起来。

  2. 我该用哪个？（决策表）
  3. 完整例子：从零做一个课题
  4. 概念详解
  5. 安全性与花费

五个概念，一句话各一个

概念一句话在哪
Harness 一个 Agent 的"人设 + 装备"：角色提示、能用哪些工具、看得见哪些技能、记忆范围、轮数和预算上限、什么事要问你。 侧边栏 Harness
记忆 跨对话记住的事实，分三层：全局（所有项目）、项目、本对话。纯 Markdown 文件，你能直接看和改。 侧边栏 记忆
主对话super agent 每个项目一个常驻对话。它除了自己干活，还能在这个项目里开新对话、把活分出去——派出来的是真对话，你随时能点进去接手。 项目页「打开主对话」
Loopworkflow 把多个 Agent 和检查点连成的固定流程图：谁先做、做完谁检查、不合格重做几轮、什么时候停、花多少钱为止。 侧边栏 Loop 设计器
主理人 一个特殊的 Agent，它的活是扩展这个软件本身：为你的领域生成新的 Harness、技能、Loop、领域包，写完直接存好。 对话顶栏把 Harness 切成「主理人」

我该用哪个？

这张表比任何说明都管用，先看这个：

你的情况用什么
一个问题、一次探索、读一个文件普通对话
一件事要做很多步，但每次做法都不一样主对话派活
同一套步骤要重复跑（每批数据、每篇稿子、每月一次）Loop
这个课题的具体事实：被试数、采样率、路径、命名约定记忆
这个领域的通用做法：方法学要求、单位约定、必须过的检查技能（让主理人写）
软件里没有适合我这行的预设主理人

最容易搞混的一对：主对话派活 vs Loop。派活是临机决定——它看情况决定开几个对话、分别干什么；Loop 是固定流程——你画好的图，每次都照着走，有验证门和重试轮数。第一次做一件事用派活，做顺了以后把它固化成 Loop。

完整例子：从零做一个课题

课题：婴儿睡眠脑电的自动分期。目标是两天内拿到一份带引用的综述（lit/review.md）和一张能复现的图（figures/stage-dist.png）。原始数据在一块外置硬盘上，不能被改动。

0

建项目，把数据挂进来

项目 → 新建项目

名称填「婴儿睡眠分期」，领域选神经科学，目录勾上 plan lit notes results figures paper。领域决定了默认打开哪些工具、推荐哪些技能，以及往系统提示里加哪段领域说明。

建好之后，在项目页的「文件夹」卡片里，把外置硬盘上的原始数据目录直接拖进去（也可以点「选择文件夹」）。拖进来默认是只读：

主文件夹   ~/Agent4Sci/婴儿睡眠分期         可读写
副文件夹   /Volumes/EEG2024/raw             只读   ← 原始数据
副文件夹   /Volumes/Share/组内共享结果        可读写

只读的文件夹，Agent 能读能搜但写不进去，命令行伸进去也不会被当成"跑出项目"拦下来。原始数据不会被任何一步改动。

1

把课题常识写进记忆

任意对话 → 悬停一条消息 → 书签图标「记住这条」

新建一个对话，先把这个课题的硬事实告诉它：

这个课题的几个固定事实，记到项目记忆里：
- 数据是 2024 年采的 32 名婴儿，月龄 3–11 个月，EGI 128 导，采样率 250 Hz
- 分期标准用 AASM 婴儿版，N1 不单独分，合并进 N2
- 被试 07 和 19 的第二段记录有电极脱落，分析一律排除
- 结果文件命名 sub-<ID>_task-sleep_desc-<内容>.csv

然后把这条消息记住：鼠标移到消息上，下面出现一排小按钮，点书签那个，选「项目」作用域。或者跑完一轮之后点顶栏的「整理记忆」，它会从这段对话里提议一批记忆，你勾选保存。

为什么值得花这两分钟：之后这个项目里每一个对话、每一个派生对话、每一次 Loop 运行，开场就知道"被试 07 和 19 要排除"。不记的话，你得在每个对话里重说一遍——而漏说一次就是一个错误的结果。

记下来的东西在侧边栏记忆页能看到、改、删。它们就是项目里的 Markdown 文件（.a4s/memory/），能进 git，能和论文一起归档。

2

主对话派活super agent

项目页 → 打开主对话（或侧边栏顶部的「主对话」按钮）

主对话是这个项目的常驻对话。给它一个大活，它会先列清单、再把能并行的部分分出去：

这个课题要在两天内出一份综述和一张图。分头做：

1. 文献这块：检索 2020 年以后婴儿/新生儿睡眠脑电自动分期的工作，
   重点是用了哪些特征、报了什么准确率、样本量多大，写进 lit/review.md，
   引用都要能查证。
2. 数据这块：读 /Volumes/EEG2024/raw 下的分期标注文件（不要改动原始数据），
   统计每个睡眠阶段的时长占比，按被试和月龄分组，
   结果写 results/stage-dist.csv，图画到 figures/stage-dist.png。

两件事互相不依赖，同时开两个对话做。做完各自报给我。

接下来你会看到三件事：

  • 顶栏下面出现一条任务清单，显示它打算分几步、现在做到哪一步（1/4）。点开能看全部，做完的会划掉。
  • 侧边栏冒出两个新对话，缩进在主对话下面，标题就是它给的任务名。它们是真对话——点进去能看全过程，能直接插话改要求，能接手自己干。
  • 派生对话跑完，结论会回到主对话里。

派生对话会花钱，而且是各花各的。每个派生对话有自己的预算（跟它的 Harness 走）。上限是同时最多 6 个在跑、项目里未归档的最多 24 个。安全级别跟随主对话——主对话设成「全部允许」，派出去的也是。

3

用 Loop 把综述流程跑成固定流水线workflow

侧边栏 Loop 设计器 → 左边挑「文献综述」模板 → 复制为我的 Loop → 运行

上一步是临机派活。如果这类综述你每个课题都要做一遍，就该用 Loop 了。内置的「文献综述」模板是这样一条流水线：

开始
 └─ 综述范围      写出纳入标准 plan/brief.md     ← 人工检查点
 └─ 检索与阅读    文献专员做系统检索，写 lit/review.md
 └─ ┌ 写作 ⟲ 评审 ────────────────── 最多 3 轮 ┐
    │   撰写综述  →  评审                       │
    └── 直到评审 decision == 'accept' 才退出 ───┘
 └─ 规则检查      引用能不能查证、产物在不在、数字有没有来源
 └─ 整理记忆      把这轮学到的写进项目记忆
结束

点运行，填一个参数（综述主题），它就自己跑了。几个 Loop 独有、对话做不到的东西：

  • 验证门：节点可以是一条命令，用退出码或指标判定通过与否，不通过就重做。
  • 人工检查点：跑到这儿停下来等你批准/反馈/选择，错一步代价大的地方放一个。
  • 循环与保留：写—评—改最多几轮、什么条件算过、每轮的产物保留还是回滚。
  • 并行展开：对一个列表（比如 20 篇待读文献）并行跑同一个子图。
  • 预算与 git 提交：整条流水线一个总预算；每个节点跑完自动 git 提交，哪一步做坏了能回到上一步。

运行过程在侧边栏运行监控里看：每个节点的状态、花了多少、卡在哪。

内置模板是只读的，点「复制为我的 Loop」之后才能改。除了文献综述，还有数据分析、机器学习实验、自主研究、写作—评审、Best-of-N、想法锦标赛等十个模板。

4

让主理人给这个方向造一套配置

新建对话 → 顶栏 Harness 切成 主理人

内置的 Harness（研究助手、文献专员、数据分析师、实验员、写作者、评审）是通用的。你这个方向有自己的规矩，就让主理人固化下来：

我做婴儿睡眠脑电分期。给我配两样东西：

1. 一个专门的 Harness「睡眠分期分析师」：
   做分期相关的数据分析，必须先检查采样率和导联数对不对、
   必须排除记忆里标记的坏被试、每个统计量都要报 n 和置信区间，
   不许在看过结果之后改分组标准。

2. 一个技能，写清楚婴儿睡眠分期的方法学要求：
   AASM 婴儿版和成人版的区别、月龄分组的惯例、
   常见的坑（比如 active sleep 和 REM 的对应关系）、
   结果可信之前必须过的检查清单。

它会先用一次提问把需要你定的几件事问清楚（一次问完，每个都给选项），然后直接把东西存好，并告诉你叫什么、在哪、怎么用。去 Harness 页和技能页就能看到。

主理人能造四种东西：Harness（一个角色）、技能（按需加载的领域知识）、Loop（可重复的流程）、领域包（新建项目时可选的研究领域，带默认工具、推荐技能、领域说明）。

5

把这次的做法沉淀成技能

对话顶栏 ⋯ → 从这段对话提炼技能

综述做完了、图也出了。这次摸索出来的做法——怎么从那种标注文件里读分期、哪几个字段要对齐、画图用什么参数——下次不该再摸索一遍。

点「从这段对话提炼技能」，它会另外跑一次模型读这个对话的过程记录，把值得复用的做法写成技能，存到项目的 skills/learned。

提炼出来的技能默认是待批准状态，对 Agent 不可见。去 技能 → 待批准 看内容和安全扫描报告，批准之后才生效。高风险内容会被直接拒掉。

两天之后你手里有什么

  • lit/review.md 和 references.bib——引用都经过核验
  • results/stage-dist.csv、figures/stage-dist.png——每个数字都能追到产生它的代码
  • 一份项目记忆，下个对话开口就知道这个课题的规矩
  • 一个「睡眠分期分析师」Harness 和两个技能，下个课题直接用
  • 一条跑通的 Loop，下次换个主题点一下运行
  • 完整的 git 历史，每一步都能回退

概念详解

记忆：三层作用域

作用域放什么
全局跨所有项目都成立的：你是谁、偏好什么统计方法、实验室的命名约定、常用的机器配置。
项目这个课题的事实：被试、设备参数、排除标准、文件约定。最常用的一层。
本对话只在这一串对话里成立的临时结论。

对话顶栏的记忆模式决定这个对话看得见哪几层：选「全局记忆」看得见三层，「项目记忆」看得见项目+本对话，「仅本对话」只看自己，「无」什么都不读写（临时对话就是这个）。

只有索引进系统提示，正文是 Agent 按需去读的——所以记一百条也不会把上下文撑爆，但标题要写得像话，不然它找不到。

主对话能做什么

主对话的 Agent 比普通对话多五个工具：开新对话并派活、列出项目里的对话、读某个对话最近的内容、给某个对话再派一轮或纠偏、停掉跑偏的对话。

派活可以等（默认，等它做完把报告拿回来）也可以不等（先把几件事全派出去，再逐个去收）。派生对话沿用主对话的 Harness、模型和安全级别。

这组工具只有主对话有，所以派生对话不能再往下派——不会出现失控的层层分裂。

安全性与花费

三档权限

在输入框右下角切换，随时可改，不用重启：

档位什么时候问你用在哪
总是询问写文件、跑命令、装技能、联网都要你点同意；读取和检索不打扰。刚开始用、或者在重要目录里动手
按需提问
默认		项目内的事直接做；命令伸到项目外、安装外部代码、命中危险命令时才问。日常
全部允许什么都不问，危险命令拦截也关掉。只在无人值守且信任这条流程时

审批弹窗上有「允许，并且不再问」——选了之后这一类在这个对话里就不再打扰你，而且换设置、重开应用都还记得。

花费

  • 每个对话顶栏显示已花多少钱和上下文占用。
  • Harness 上能设每次运行的预算上限和最大轮数，Loop 另有整条流水线的总预算。到顶会停下来并说明原因。
  • 派生对话、子代理、提炼技能都是另外的模型调用，各花各的。
  • 本地跑 Ollama 模型是免费的，适合干粗活（整理、分类、初筛）。

数据在哪

全部在本机。项目文件在你指定的文件夹，对话和记忆在应用数据目录，API Key 存在系统钥匙串（macOS 钥匙串 / Windows 凭据管理器），备份里不含密钥。只有你调用的模型厂商会收到你发出去的内容。

第三方代码的风险：技能和 MCP 服务器是外部代码，装之前会扫描，但扫描不是沙箱。只装你信得过来源的东西。Agent 自己提炼的技能默认待批准，你看过才生效。

常见问题

它跑着跑着我想改要求，怎么办？

直接在输入框里打字发出去。输入框右下角有个开关决定行为：插话会立刻打断当前这一步，排队会等这一轮跑完再发。按「停止」会真的停住——排在后面的消息不会偷偷发出去。

对话写到一半切走了，内容还在吗？

在。草稿和拖进来的附件都按对话保存，切回来原样还在。

怎么把一段结论拿出去？

悬停任意一条消息，下面有复制、引用到输入框、记住这条。代码块右上角有单独的复制按钮。整个对话用顶栏 ⋯ → 复制整个对话 / 导出为 Markdown 文件。

它说它做了，但我不确定真做了没有？

看工具调用卡片——每一步调了什么、返回了什么都在里面展开。文件系统是实打实的，去项目文件夹里看就知道。重要的数字可以用「发现账本」和溯源检查来验证来源。

我改过的 Harness 为什么没有新功能？

自己改存过的 Harness 不会自动获得新加的工具组。去 Harness 页在工具箱里勾上就行（比如新加的「任务清单」）。内置的几个会自动带上。

换了设置要重启吗？

不用。安全级别、Harness、模型、最大轮数这些改完下一轮就生效。
